## Miscellaneous

You can spot a real data engineer in one question.
I never ask what a medallion architecture is - I ask what they'd change about the one they built.
If they built it, the answer comes fast, and they're usually still a little annoyed about it. A silver table nobody could query.
A cluster bill someone had to go explain to finance.
If they only read about it, they describe the diagram again.
Same question, same fifteen minutes, and I know which one I'm talking to.
You don't remember the pain of a system you didn't build.
